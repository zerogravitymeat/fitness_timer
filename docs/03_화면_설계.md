## 1. 화면 목록과 이동 흐름

| ID | 화면 | 진입 경로 |
|---|---|---|
| S1 | 홈 (루틴 목록) | 앱 실행 |
| S2 | 루틴 편집 | 홈의 `+`, 루틴 메뉴의 "수정"·"복사해서 수정" |
| S3 | 진행 | 홈에서 루틴이나 코스의 ▶ |
| S4 | 결과 | 진행 완료 또는 중단 |
| S5 | 설정 | 홈 우측 상단 ⚙ |
| S6 | 정식 버전 구매 (결제 화면) | 체험 종료 후 잠긴 기능, 결과 화면 안내, 홈 배지, 설정 |
| S7 | 코스 편집 | 홈의 "새 코스", 코스 메뉴의 "수정"·"복사해서 수정" (4-1장) |
| D1 | 이어하기 확인 (다이얼로그) | 비정상 종료 후 앱 실행 |
| D2 | 권한·TTS 안내 (바텀시트) | 첫 타이머 시작 직전 |

```
            ┌──────────── ⚙ ───────────→ S5 설정
            │
앱 실행 → S1 홈 ── ▶ ──→ (D2 첫 실행만) → S3 진행 ──완료/중단──→ S4 결과
            │   ↑                               │                    │
            │   └────────── 홈으로 ──────────────┼────────────────────┘
            │                                   └ 다시 하기 → S3
            └── + / 수정 ──→ S2 편집 ── 저장 ──→ S1 (저장 후 바로 시작 가능)
```

**시작까지의 터치 수 (목표: 3번 이내, 01 문서 2장)**
- 최근·즐겨찾기·프리셋 루틴: 홈에서 ▶ **1번**
- 첫 실행: ▶ → 권한 허용 → 시작 = **3번**

## 2. 공통 규칙

### 2.1 구간 색상 (실제 색상 값은 [04. 디자인 가이드](04_디자인_가이드.md) 2.2절)

| 구간 | 색상 역할 | 이유 |
|---|---|---|
| 준비 | 노랑 계열 | 곧 시작함 |
| 운동 | 빨강·주황 계열 | 힘쓰는 중 |
| 휴식 | 초록 계열 | 쉬는 중 |
| 세트 간 휴식 | 파랑 계열 | 긴 휴식, 일반 휴식과 구분 |
| 일시정지 | 회색 | 멈춤 상태 |
| 완료 | 강조색 | |

- 진행 화면은 어두운 바탕 위에 구간 색을 **화면 대부분에 빛처럼 번지게** 깐다. 2~3m 떨어진 곳에서도 지금 무슨 구간인지 색만으로 알 수 있게 하기 위해서다 (04 문서 2.3절).
- 색만으로 구분하지 않는다. 구간 이름 글자를 항상 같이 표시한다 (색각 이상 사용자 고려).

### 2.2 크기와 터치

| 요소 | 기준 |
|---|---|
| 진행 화면 버튼 | 높이 72dp 이상, 버튼 사이 간격 16dp 이상 |
| 그 밖의 버튼·터치 영역 | 48dp 이상 (Android 기본 기준) |
| 진행 화면 남은 시간 숫자 | 세로 화면에서 화면 너비의 70% 이상을 차지하도록 자동 조절 |

### 2.3 화면 방향

- 홈, 편집, 설정, 결과: 세로 고정
- 진행: 세로·가로 모두 지원. 폰을 가로로 세워두는 사용자가 많기 때문이다 (3.3절 가로 배치)

### 2.4 테마

- MVP는 다크 테마만 제공한다 (04 문서 2.4절). 라이트 모드는 2차에서 검토한다.

### 2.5 광고 없음, 구매 안내 원칙

- 앱 어디에도 광고를 넣지 않는다 (01 문서 7장).
- 구매 안내는 **진행 화면에 절대 띄우지 않는다.** 홈 배지, 결과 화면, 잠긴 기능을 눌렀을 때만 보여준다 (02 문서 10.4절).

## 3. S1 홈 (루틴 목록)

```
┌─────────────────────────────┐
│ Fitness Timer            ⚙  │
│ (무료 운동 7회 남음)          │  ← 체험 중에만, 탭하면 S6
├─────────────────────────────┤
│ 최근                         │
│ ┌─────────────────────────┐ │
│ │ 하체 루틴           ★   │ │
│ │ 12회 × 3세트 · 2-0-1    │ │
│ │ 약 7분          [ ▶ ]   │ │  ← 큰 카드, 바로 시작
│ └─────────────────────────┘ │
│                             │
│ 즐겨찾기                     │
│ ┌──────────┐ ┌──────────┐   │
│ │ 타바타 ★ │ │ 아침 HIIT│   │  ← 가로 스크롤
│ │ 4분  [▶] │ │ 9분  [▶] │   │
│ └──────────┘ └──────────┘   │
│                             │
│ 프리셋                       │
│  타바타   20초/10초 × 8  [▶] │
│  HIIT    40초/20초 × 8  [▶] │
│  플랭크   30초/30초 × 3  [▶] │
│  근력 세트  15회 × 3세트  [▶] │
│                             │
│ 내 루틴          최근 사용순 ▾│
│  하체 루틴  12회 × 3세트  [▶] │
│  아침 HIIT 45초/15초 × 10 [▶]│
│                       (＋)   │  ← 새 루틴 버튼
└─────────────────────────────┘
```

### 구성
| 영역 | 내용 | 표시 조건 |
|---|---|---|
| 최근 | 마지막으로 시작한 루틴 1개를 큰 카드로 | 사용 기록이 있을 때 |
| 즐겨찾기 | 즐겨찾기한 루틴, 가로 스크롤 | 즐겨찾기가 1개 이상일 때 |
| 코스 | 코스 목록 + "새 코스" 버튼 (02 문서 8-1장) | 코스가 있으면 프리셋 **위**에. 없으면 맨 아래에 안내와 "새 코스" 버튼. 내 루틴이 없으면 "새 코스"는 비활성이고 "내 루틴을 먼저 만들면, 그 루틴들을 골라 코스로 묶을 수 있어요" 안내 |
| 프리셋 | 프리셋 4개 (02 문서 4장) | 항상 |
| 내 루틴 | 커스텀 루틴 목록과 정렬 선택 | 항상. 비어 있으면 "자주 하는 운동을 루틴으로 저장해 보세요" 안내와 만들기 버튼 |

### 루틴 항목
- 요약 표기
  - 시간 모드: `운동/휴식 × 라운드` (+ 세트 수가 2 이상이면 `× 세트`). 예: `20초/10초 × 8`
  - 횟수 모드: `목표 횟수 × 세트 · 템포`. 예: `12회 × 3세트 · 2-0-1`
- 예상 시간: 1분 이상이면 "약 N분", 1분 미만이면 "N초"
- **▶ 버튼**: 바로 진행 화면으로 간다
- **항목 탭**: 루틴 메뉴(바텀시트)를 연다
- **항목 길게 누르기**: "순서 편집" 모드로 들어간다 (2026-11-19 변경)
  - 프리셋과 내 루틴 항목에 손잡이(≡)가 나타나고, 손잡이를 끌거나 항목을 다시 길게 눌러 끌면 위아래로 옮길 수 있다. 프리셋은 프리셋끼리, 내 루틴은 내 루틴끼리만 옮긴다.
  - 상단 "완료" 또는 뒤로 가기로 끝낸다. 편집 중에는 최근·즐겨찾기·시작 버튼을 숨긴다.
  - 바꾼 순서는 저장된다. 내 루틴 순서를 바꾸면 정렬이 "직접 정렬"로 바뀐다.
  - 최근 카드와 즐겨찾기 카드는 길게 눌러도 루틴 메뉴를 연다 (순서를 바꿀 수 없는 영역).
- **체험 종료 후 내 루틴**: ▶ 자리에 자물쇠 아이콘을 표시하고 약간 흐리게 한다. 누르면 S6으로 간다. `+` 버튼도 S6으로 간다.

### 코스 항목 (2026-11-20 추가)
- 왼쪽에 색 막대 세 개 (루틴 여러 개가 이어진 모양)
- 이름, 루틴 순서 `타바타 → 근력 세트 → 플랭크`, `루틴 3개 · 약 18분`
- ▶ 바로 시작, 탭하면 코스 메뉴 (시작 / 수정 / 복사해서 수정 / 삭제), 길게 누르면 순서 편집 (코스끼리만)
- 체험 종료 후에는 내 루틴처럼 자물쇠

### 루틴 메뉴 (바텀시트)
| 메뉴 | 프리셋 | 내 루틴 |
|---|---|---|
| 시작 | O | O |
| 즐겨찾기 추가/해제 | O | O |
| 수정 | - | O |
| 복사해서 수정 | O | O |
| 삭제 | - | O (확인 다이얼로그) |

## 4. S2 루틴 편집

```
┌─────────────────────────────┐
│ ←  루틴 편집                 │
├─────────────────────────────┤
│ 이름  [ 하체 루틴          ] │
│                             │
│ 운동 방식                    │
│ [   시간   |  ■ 횟수   ]     │  ← 세그먼트 버튼
│                             │
│ 준비          [−]  10초 [+]  │
│ 목표 횟수      [−]  12회 [+]  │
│ 템포  (천천히)(■보통)(빠르게)(직접)│
│       내려가기 2 · 멈춤 0 · 올라오기 1│
│ 세트          [−]   3  [+]   │
│ 세트 간 휴식    [−] 1:30 [+]  │
│                             │
│ ▸ 더 보기                    │  ← 접힘
│   마지막 세트 휴식 건너뛰기 [●]│
│   음성 안내 방식  숫자만 ▾     │
├─────────────────────────────┤
│ 예상 시간 약 7분              │
│ [   저장   ]  [ 저장 후 시작 ] │
└─────────────────────────────┘
```

### 운동 방식에 따라 보이는 항목

| 항목 | 시간 모드 | 횟수 모드 |
|---|---|---|
| 준비 | O | O |
| 운동 시간 | O | - |
| 목표 횟수 | - | O |
| 템포 | - | O |
| 휴식 | O ("휴식") | O ("세트 간 휴식") |
| 라운드 | O ("라운드") | O ("세트") |
| 세트 / 세트 간 휴식 | O (세트 2 이상일 때 세트 간 휴식 표시) | - (02 문서 2.5절) |
| 마지막 라운드 휴식 건너뛰기 | O (더 보기) | O ("마지막 세트 휴식 건너뛰기", 더 보기) |
| 음성 안내 방식 | - | O (더 보기) |

### 입력 방식
- **숫자 항목**: `[−] 값 [+]` 스테퍼를 쓴다. 길게 누르면 값이 빠르게 바뀐다.
- **시간 항목**: 값을 탭하면 `분:초` 휠 선택기를 연다. 스테퍼 단위는 60초 미만은 5초, 60초 이상은 15초로 한다.
- **템포**: 빠른 선택 칩 3개(천천히 3-1-2 / 보통 2-0-1 / 빠르게 1-0-1)와 "직접"을 둔다. "직접"을 고르면 세 값을 0.5초 단위 스테퍼로 입력한다.
- 범위를 벗어난 값은 입력할 수 없다. 최솟값·최댓값에서는 버튼을 비활성화한다.

### 하단 고정 영역
- **예상 시간**: 값을 바꿀 때마다 바로 다시 계산한다.
- **저장**: 저장하고 홈으로 간다.
- **저장 후 시작**: 저장하고 바로 진행 화면으로 간다.
- 저장하지 않고 뒤로 가면 "변경 사항을 버릴까요?"라고 확인한다.

## 4-1. S7 코스 편집 (2026-11-20 추가)

```
┌─────────────────────────────┐
│ ←  코스 편집                 │
├─────────────────────────────┤
│ 이름 [ 아침 코스          ]   │
│                             │
│ 루틴 순서                     │
│ ┌─────────────────────────┐ │
│ │ ① 타바타  20초/10초×8  ✕ ≡│ │
│ └─────────────────────────┘ │
│   │ (휴식 1분)               │  ← 눌러서 바꾸기
│ ┌─────────────────────────┐ │
│ │ ② 근력 세트 15회×3세트 ✕ ≡│ │
│ └─────────────────────────┘ │
│   │ (휴식 없이 바로)          │
│ ┌─────────────────────────┐ │
│ │ ③ 플랭크  30초/30초×3  ✕ ≡│ │
│ └─────────────────────────┘ │
│ [        ＋ 루틴 추가        ] │
├─────────────────────────────┤
│     루틴 3개 · 약 18분        │
│ [  저장  ]  [ 저장 후 시작 ]   │
└─────────────────────────────┘
```
- **루틴 추가**: 바텀시트에서 내 루틴 중 하나를 누르면 맨 뒤에 들어간다. 최대 20개.
- **순서 바꾸기**: 손잡이(≡)를 끌어서. 루틴 사이 휴식은 그 앞 루틴에 붙어서 함께 움직인다.
- **빼기**: ✕
- **루틴 사이 휴식**: 칩을 누르면 바텀시트에서 `없음 / 15초 / 30초 / 1분 / 1분 30초 / 2분 / 3분 / 직접(분:초 휠)` 중에서 고른다. 없음이면 칩에 "휴식 없이 바로".
- 저장은 이름이 있고 루틴이 1개 이상일 때만 된다. 나갈 때 바뀐 내용이 있으면 버릴지 묻는다.

## 5. S3 진행 화면

### 5.1 시간 모드 (세로)

```
┌─────────────────────────────┐
│ 타바타              ✕ 숨김   │  ← 상단: 루틴 이름
│                             │
│          운동                │  ← 구간 이름 (큰 글씨)
│                             │
│        0:17                 │  ← 남은 시간 (화면 최대 크기)
│                             │
│  ━━━━━━━━━━━━━━━━░░░░░░░░░   │  ← 구간 진행 바
│                             │
│   라운드 3 / 8   세트 1 / 2   │
│   다음: 휴식 10초             │
│   전체 남은 시간 2:43         │
│                             │
│ ┌──────┐┌──────────┐┌──────┐│
│ │  ⏮   ││    ⏸     ││  ⏭   ││  ← 72dp 이상
│ │ 이전 ││  일시정지  ││ 다음 ││
│ └──────┘└──────────┘└──────┘│
└─────────────────────────────┘
       배경 전체 = 운동 색
```

- 휴식·세트 간 휴식 구간에서는 **`+10초` 버튼**을 "다음 구간" 위에 추가로 표시한다.
- 남은 시간이 1분 이상이면 `M:SS`, 1분 미만이면 `0:SS`로 표시한다.
- 마지막 3초에는 숫자가 커졌다 작아지는 효과로 카운트다운을 강조한다.

```
┌─────────────────────────────┐
│ 하체 루틴                     │
│                             │
│        내려가기               │  ← 현재 동작 (큰 글씨)
│                             │
│         7                   │  ← 현재 회차 (화면 최대 크기)
│        / 12                 │
│                             │
│  [ 내려가기 ███▓░ | 올라오기 ░ ]│  ← 템포 바: 1회 안에서 위치 표시
│                             │
│          세트 2 / 3          │
│   다음: 세트 간 휴식 1:30      │
│                             │
│ ┌──────┐┌──────────┐┌──────┐│
│ │  ⏮   ││    ⏸     ││  ✓   ││
│ │ 이전 ││  일시정지  ││세트 완료││
│ └──────┘└──────────┘└──────┘│
└─────────────────────────────┘
```

- **템포 바**: 1회 동작을 `내려가기 | 멈춤 | 올라오기` 비율대로 나누고, 지금 위치를 표시 막대가 따라간다. 멈춤이 0초면 그 칸은 그리지 않는다.
- 현재 동작 글자("내려가기"·"멈춤"·"올라오기")는 비프음과 같은 순간에 바뀐다.
- 운동 구간의 배경은 운동 색이다. 내려가기와 올라오기를 밝기 차이로만 살짝 구분한다.
- 세트 간 휴식 구간은 5.1의 휴식 화면과 같은 배치를 쓴다. 구간 이름은 "세트 간 휴식", 진행 정보는 `세트 2 / 3 완료`로 표시한다.

### 5.3 가로 배치

```
┌───────────────────────────────────────────────┐
│ 운동                     라운드 3/8 · 세트 1/2 │
│                                     ┌───────┐ │
│          0:17                       │ ⏮ 이전 │ │
│                                     ├───────┤ │
│  ━━━━━━━━━━━━━━━━░░░░░░              │ ⏸     │ │
│  다음: 휴식 10초                     ├───────┤ │
│                                     │ ⏭ 다음 │ │
│                                     └───────┘ │
└───────────────────────────────────────────────┘
```
- 왼쪽 약 70%에 남은 시간(또는 회차)을, 오른쪽에 버튼을 세로로 배치한다.

### 5.4 상태별 동작

| 상태 | 화면 |
|---|---|
| 시작 직후 | 준비 구간부터 시작한다. 준비가 0초면 바로 첫 운동으로 간다 |
| 일시정지 | 배경을 회색으로 바꾸고, 남은 시간 위에 "일시정지"를 표시한다. 가운데 버튼은 **▶ 재개**로 바뀐다. 버튼 줄 아래에 **"운동 끝내기"** 버튼이 나타난다 |
| 운동 끝내기 | 확인 다이얼로그 "운동을 끝낼까요?" [계속하기] [끝내기] → S4 |
| 완료 | 완료 색 배경에 "완료!"를 1.5초 보여준 뒤 S4로 자동 이동한다 |
| 뒤로 가기 버튼 | 일시정지 상태로 바꾸고 "운동 끝내기" 확인 다이얼로그를 띄운다 |

- **실수로 끝나지 않게** 하기 위해, 진행 중에는 중단 버튼을 보여주지 않는다. 일시정지한 뒤에만 끝낼 수 있다.
- 상단의 "숨김"은 상태 표시줄과 내비게이션 바를 숨기는 전체 화면 전환 버튼이다.

- 잠금 화면에도 같은 내용을 표시한다.

## 8. 다이얼로그와 안내

### D1 이어하기 확인
- 표시 조건: 앱을 실행했는데 저장된 진행 상태가 있고, 저장된 지 30분이 지나지 않았을 때 (02 문서 7장)
- 문구: "진행 중이던 **타바타**를 이어서 할까요? (라운드 3/8)"
- 버튼: [처음부터] [버리기] [이어서 하기]
- "이어서 하기"를 누르면 일시정지 상태의 S3에서 시작한다. 사용자가 재개를 눌러야 진행된다.

### D2 권한·TTS 안내 (첫 타이머 시작 직전에 한 번만)
```
┌─────────────────────────────┐
│ 화면이 꺼져도 타이머가          │
│ 계속되도록 알림을 허용해 주세요 │
│                             │
│ [ 알림 허용하기 ]              │  → Android 시스템 권한 요청
│                             │
│ (한국어 음성이 없을 때만)        │
│ 음성 안내를 들으려면 한국어      │
│ 음성을 설치해 주세요            │
│ [ TTS 설정 열기 ]  [ 나중에 ]   │
└─────────────────────────────┘
```
- 앱을 처음 열 때가 아니라 **첫 ▶를 누른 순간**에 보여준다. 첫 화면에서 바로 루틴을 고를 수 있게 하기 위해서다.
- Android 13 이상에서는 알림 권한(`POST_NOTIFICATIONS`)을 요청한다. 거부해도 타이머는 시작된다. 다만 백그라운드 알림 표시는 제한된다는 안내를 한 줄로 보여준다.
