## 1. 콘셉트

**어두운 바탕 + 구간 색 빛 번짐 + 반투명 유리 패널**

- 바탕은 거의 검은 남색이다. 그 위에 구간 색 두 개를 큰 원형 그라데이션으로 번지게 깐다. 화면 전체를 원색으로 칠하지 않는다.
- 정보는 반투명 유리 패널(블러 + 얇은 흰 테두리) 위에 올린다.
- **촌스럽지 않게 하는 원칙**
  1. 원색(#FF0000, #00FF00 같은 값)을 쓰지 않는다. 모든 구간 색은 채도와 밝기를 비슷하게 맞춘 한 가족으로 만든다.
  2. 구간마다 **한 색이 아니라 가까운 두 색의 그라데이션**을 쓴다 (예: 코랄 → 오렌지). 단색보다 깊이감이 생긴다.
  3. 색은 배경에서만 크게 쓴다. 글자와 아이콘은 흰색 계열로 통일한다.
  4. 강조 버튼(가운데 일시정지 등)은 거의 불투명한 흰색으로 둔다. 색을 더 얹지 않는다.

## 2. 색상

### 2.1 기본 색

| 토큰 | 값 | 용도 |
|---|---|---|
| `bg.base` | `#0B0F1A` | 모든 화면의 바탕 |
| `text.primary` | `#FFFFFF` | 진행 화면 글자 |
| `text.body` | `#F4F6FB` | 일반 화면 본문 |
| `text.secondary` | `#B7BFD0` | 보조 글자 (요약, 섹션 제목) |
| `text.tertiary` | `#8E97AB` | 비활성, 잠긴 루틴 |

### 2.2 구간 색

| 구간 | 이름 | 색 1 (주) | 색 2 (보조) | 버튼 그림자 |
|---|---|---|---|---|
| 준비 | Honey Amber | `#F6B44B` | `#E9795B` | `#F6B44B` 35% |
| 운동 | Coral Flame | `#FF5D6C` | `#FF8A4C` | `#FF5D6C` 35% |
| 휴식 | Mint Lagoon | `#2FD3A7` | `#1C9FB8` | `#2FD3A7` 35% |
| 세트 간 휴식 | Indigo Dusk | `#6C7CFF` | `#9B6BFF` | `#6C7CFF` 35% |
| 일시정지 | Slate Mist | `#8A94A6` | `#4B5468` | 없음 |
| 완료 | Aurora | 운동·휴식·세트 간 휴식 색 1을 함께 사용 | | |

- 구분이 쉽도록 **색상(hue)이 크게 떨어지게** 골랐다. 준비(노랑)와 운동(빨강)은 같은 따뜻한 계열이지만 밝기 차이로 구분된다.
- 운동(따뜻한 색)과 휴식(차가운 색)은 색각 이상이 있어도 밝기와 온도 차이로 구분된다. 그래도 구간 이름 글자는 항상 함께 표시한다 (03 문서 2.1절).

### 2.3 진행 화면 배경 만들기

```
배경 = bg.base
     + 원형 그라데이션(색 1, 불투명도 0.8~0.9, 왼쪽 위 10%·8% 지점, 반경 55%)
     + 원형 그라데이션(색 2, 불투명도 0.75~0.85, 오른쪽 아래 95%·70% 지점, 반경 55%)
```
- 구간이 바뀌면 배경을 **600ms 동안 서서히 바꾼다** (크로스페이드).
- 빛 번짐이 천천히 움직이는 효과는 선택 사항이다. 배터리 절약 모드에서는 끈다.

### 2.4 홈·편집·설정 화면 배경

- 같은 `bg.base` 위에 인디고(45%), 코랄(35%), 민트(30%)를 약하게 깐다. 진행 화면보다 차분하게 한다.
- 라이트 모드는 2차에서 검토한다. MVP는 **다크 테마만** 제공한다. 03 문서 2.4절의 "시스템 설정 따름"을 대체한다.

## 3. 유리 패널 (Glass)

| 토큰 | 값 |
|---|---|
| 채움 | 흰색 10% (`rgba(255,255,255,0.10)`) |
| 테두리 | 1px, 흰색 22% |
| 블러 | 24px + 채도 140% |
| 그림자 | `0 8px 32px` 검정 25% |
| 모서리 | 큰 패널 24px, 버튼 22px, 작은 버튼 14px, 알약형 999px |

| 단계 | 채움 / 테두리 | 쓰는 곳 |
|---|---|---|
| 약한 유리 | 6% / 14% | 홈 목록 묶음 |
| 기본 유리 | 10% / 22% | 정보 카드, 보조 버튼 |
| 강한 유리 | 14% / 26% | 구간 이름 알약, +10초 버튼 |
| 불투명 흰색 | 92% | 주요 버튼 (일시정지·재개, 홈의 ▶) |

### Flutter 구현 메모
- 유리 효과는 `ClipRRect` + `BackdropFilter(ImageFilter.blur(sigmaX: 12, sigmaY: 12))`로 만든다. CSS 24px 블러는 Flutter sigma 약 12에 해당한다.
- **성능**: `BackdropFilter`는 저사양 Android에서 무겁다.
  - 진행 화면은 유리 패널 3~4개까지만 쓴다.
  - **스크롤되는 목록 항목에는 `BackdropFilter`를 쓰지 않는다.** 반투명 채움과 테두리만 쓴다. 배경이 고정된 그라데이션이라 눈으로 보이는 차이가 거의 없다.
  - 저사양 기기에서 프레임이 떨어지면 블러를 끄고 채움 불투명도를 높이는 대체 모드를 둔다.

## 4. 글꼴

| 용도 | 글꼴 | 비고 |
|---|---|---|
| 한글 UI | Pretendard | 무료(OFL). 앱에 포함해서 배포 |
| 숫자 (타이머, 회차, 횟수) | Pretendard의 고정폭 숫자 (`FontFeature.tabularFigures()`) | 숫자가 바뀔 때 폭이 흔들리지 않게 |

> 시안은 웹 글꼴 제약 때문에 Noto Sans KR + Inter로 그렸다. 앱에서는 Pretendard 하나로 통일한다.

| 텍스트 | 크기 | 굵기 |
|---|---|---|
| 남은 시간 (시간 모드) | 화면 너비에 맞춰 자동 조절, 기준 132sp | SemiBold |
| 현재 회차 (횟수 모드) | 기준 168sp, 목표 횟수는 40sp | SemiBold |
| 구간 이름 | 22sp, 자간 넓게 | Bold |
| 카드 제목 | 16~20sp | Bold |
| 본문 / 보조 | 14~16sp / 13sp | Regular·Medium |

## 5. 아이콘과 그림자

- 아이콘은 **선(stroke) 아이콘** 2px 두께로 통일한다. 재생 버튼만 채움으로 그린다.
- 큰 숫자에는 아주 옅은 그림자(`0 4px 30px` 검정 25%)를 줘서 밝은 빛 번짐 위에서도 또렷하게 보이게 한다.

## 6. 접근성 확인 항목

- 흰 글자가 가장 밝은 빛 번짐(민트, 앰버) 위에 올라갈 때 대비가 약해질 수 있다.
  - 작은 글자(14sp 이하)는 반드시 유리 패널 안에 둔다.
  - 실제 기기에서 대비를 확인하고, 부족하면 빛 번짐 불투명도를 0.7까지 낮춘다.
- 버튼 크기는 03 문서 2.2절 기준을 따른다 (진행 화면 72dp 이상).

## 7. 앱 구현 (2026-11-19)

- 코드 위치: `lib/design/` (`tokens.dart` 색·유리 단계, `glass.dart` 유리 패널·배경·버튼, `app_theme.dart` 테마)
- 모든 화면은 `MaterialApp.builder`의 공통 배경(2.4절) 위에 그리고, 진행 화면만 구간 색 배경(2.3절)으로 덮는다.
- 블러(`BackdropFilter`)는 진행 화면의 정보 패널 하나에만 쓴다. 목록 카드는 반투명 채움과 테두리만 쓴다.
- 횟수 모드의 휴식은 화면에서 "세트 간 휴식"이므로 인디고 색을 쓴다.
- 홈 목록 왼쪽 색 막대: 시간 모드 코랄, 횟수 모드 인디고.
- Pretendard 라이선스(OFL 1.1)는 앱의 "오픈소스 라이선스" 화면에 표시한다.
