## 1. 용어

| 용어 | 뜻 |
|---|---|
| 루틴 | 사용자가 시작하는 타이머 한 묶음. 프리셋 또는 직접 만든 루틴 |
| 구간 | 타이머가 진행하는 가장 작은 단위. 준비 / 운동 / 휴식 / 세트 간 휴식 |
| 라운드 | `운동 → 휴식` 한 번 |
| 세트 | 라운드를 정해진 횟수만큼 반복한 묶음 |
| 시간 모드 | 운동 구간이 **시간**으로 끝남 (예: 40초) |
| 횟수 모드 | 운동 구간이 **횟수**로 끝남 (예: 12회). 앱이 템포에 맞춰 횟수를 세어줌 |
| 템포 | 횟수 모드에서 1회 동작에 걸리는 시간 (초) |
| 코스 | 루틴 여러 개를 정한 순서대로 이어서 하는 묶음. 루틴 사이에 휴식을 넣거나 뺄 수 있다 (8-1장) |

## 2. 루틴 구조

```
준비
└ 세트 × N
   ├ 라운드 × M
   │   ├ 운동 (시간 또는 횟수)
   │   └ 휴식
   └ 세트 간 휴식
완료
```

### 2.1 설정 항목

| 항목 | 범위 | 단위 | 기본값 | 비고 |
|---|---|---|---|---|
| 루틴 이름 | 1~20자 | - | "내 루틴" | |
| 준비 시간 | 0~60초 | 1초 | 10초 | 0이면 준비 구간 없음 |
| 운동 종료 조건 | 시간 / 횟수 | - | 시간 | 3장 참고 |
| 운동 시간 (시간 모드) | 5초~99분 59초 | 1초 | 40초 | |
| 목표 횟수 (횟수 모드) | 1~100회 | 1회 | 12회 | |
| 템포 (횟수 모드) | 3.2절 참고 | | 1회 3초 | |
| 휴식 시간 | 0초~99분 59초 | 1초 | 20초 | 0이면 휴식 구간 없음 |
| 라운드 수 | 1~99 | 1 | 8 | |
| 세트 수 | 1~20 | 1 | 1 | 시간 모드에서만 사용 (2.5절) |
| 세트 간 휴식 | 0초~30분 | 5초 | 60초 | 세트 수가 1이거나 횟수 모드면 숨김 |
| 마지막 라운드 휴식 건너뛰기 | 켜짐 / 꺼짐 | - | 켜짐 | 2.2절 참고 |

### 2.2 구간 경계 규칙

- **마지막 라운드 휴식 건너뛰기** (루틴별 설정)
  - 켜짐: 세트의 마지막 라운드가 끝나면 휴식 없이 바로 **세트 간 휴식**으로 넘어간다. 마지막 세트라면 **완료**로 넘어간다.
  - 꺼짐: 마지막 라운드 뒤에도 휴식을 진행한 다음 세트 간 휴식으로 넘어간다.
- **루틴 맨 끝의 휴식**(마지막 세트 뒤의 세트 간 휴식, 그리고 건너뛰기를 꺼둔 경우 마지막 라운드 휴식)은 항상 건너뛰고 완료로 간다. 뒤에 운동이 없기 때문이다.
- 시간이 0으로 설정된 구간은 만들지 않는다. 안내 음성도 나오지 않는다.

### 2.3 실행 순서 예시

`준비 10초 / 운동 20초 / 휴식 10초 × 3라운드 × 2세트 / 세트 간 휴식 60초`, 마지막 라운드 휴식 건너뛰기 **켜짐**:

```
준비10 → 운동20 → 휴식10 → 운동20 → 휴식10 → 운동20
       → 세트간휴식60
       → 운동20 → 휴식10 → 운동20 → 휴식10 → 운동20 → 완료
```

### 2.4 예상 소요 시간

루틴 목록과 편집 화면에 **예상 총 시간**을 표시한다.
- 시간 모드: 모든 구간 시간의 합
- 횟수 모드: 운동 구간 시간 = `목표 횟수 × 1회 시간` (3.2절)

### 2.5 횟수 모드의 "세트" 표시

웨이트 사용자에게 익숙한 용어를 쓰기 위해, 횟수 모드에서는 **라운드를 "세트"라고 표시**한다.

| 내부 구조 | 시간 모드 표시 | 횟수 모드 표시 |
|---|---|---|
| 라운드 | 라운드 | **세트** |
| 라운드 사이 휴식 | 휴식 | **세트 간 휴식** |
| 세트 (바깥 반복) | 세트 | 사용하지 않음 (세트 수 1로 고정, 편집 화면에서 숨김) |

- 예: 횟수 모드 루틴 `12회 × 3세트, 세트 간 휴식 90초`는 내부적으로 `12회 → 휴식 90초 × 3라운드 × 1세트`이다.
- 편집 화면, 진행 화면, 알림 영역, 음성 안내, 결과 화면 모두 이 표시 규칙을 따른다.
- 시간 모드 루틴을 횟수 모드로 바꾸면, 세트 수가 2 이상인 경우 "세트 반복 설정이 사라집니다"라고 확인을 받고 세트 수를 1로 바꾼다.

## 3. 운동 종료 조건: 시간 / 횟수

| 종료 조건 | 사용하는 경우 | 대표 운동 |
|---|---|---|
| 시간 | 정해진 시간 동안 하는 운동 | 타바타, HIIT, 플랭크 |
| 횟수 | 정해진 횟수를 채우는 운동 | 스쿼트, 푸시업, 런지, 덤벨 컬 등 근력 운동 |

종료 조건은 루틴 단위로 정한다. 한 루틴 안의 운동 구간은 모두 같은 조건을 쓴다.

### 3.1 횟수 모드: 템포 가이드 방식

앱이 정해진 템포에 맞춰 소리와 음성으로 박자를 알려주면, 사용자가 그 박자에 맞춰 동작한다. 목표 횟수를 채우면 다음 구간으로 자동으로 넘어간다.

- 센서와 카메라를 쓰지 않는다. 그래서 화면이 꺼져 있거나 이어폰만 쓸 때도 똑같이 동작한다.
- 실제 동작을 감지하지는 않는다. 사용자가 박자를 놓치면 일시정지하거나 "세트 완료"로 직접 끝낸다(5장).

> 검토 후 제외한 방식: 수동 탭 입력(운동 중 폰 조작 필요), 가속도 센서(폰 위치에 따라 오차 큼), 카메라 자세 인식(화면 켜짐·거치 필요). → 2026-11-18 결정

### 3.2 템포 설정

템포는 **1회에 걸리는 시간(초)** 하나로 정한다.

| 항목 | 범위 | 단위 | 기본값 |
|---|---|---|---|
| 1회 시간 | 1~15초 | 0.5초 | 3초 |

- 표기: `1회 3초`
- 빠른 선택 버튼: **천천히 6초** / **보통 3초** / **빠르게 2초**
- 동작을 내려가기·올라오기로 나누지 않는다. 운동마다 올리는 동작이 먼저인 것(풀업, 레그 익스텐션)과 내리는 동작이 먼저인 것(스쿼트, 푸시업)이 달라 한 순서로 정할 수 없기 때문이다. → 2026-11-26 결정
- 1.3.0까지 저장한 루틴의 `내려가기-멈춤-올라오기` 값은 세 값의 합을 1회 시간으로 읽는다.

### 3.3 횟수 모드 진행

| 시점 | 소리 | 음성 (안내 방식 "숫자만" 기준) |
|---|---|---|
| 운동 구간 시작 | 긴 비프 | - (세트·횟수는 앞 구간에서 미리 알린다) |
| 1회 완료 (= 다음 회차 시작) | 낮은 비프 | 회차 숫자 ("하나", "둘" … "열둘") |
| 목표 횟수 달성 | 완료음 | "완료" → 다음 구간으로 |

- **안내 방식** (루틴별 선택)
  - 숫자만 (기본): 회차가 바뀔 때 비프음과 회차 숫자를 함께 낸다
  - 비프만: 음성 없이 비프음만 쓴다
  - 1.3.0까지 있던 "동작 + 숫자"는 없앴다. 저장된 루틴은 "숫자만"으로 읽는다.
- 경계 규칙 (엔진 구현 시 확정)
  - 첫 회차 시작은 구간 시작의 긴 비프가 대신한다.
  - 운동 구간 시작에는 음성을 넣지 않는다. 음성이 첫 회차와 겹치면 사용자가 음성이 끝난 뒤에 움직여 회차 숫자가 하나씩 밀리기 때문이다. 세트 번호와 횟수는 준비 구간("준비하세요, 1세트 12회")과 휴식 안내에서 미리 읽는다.
  - 마지막 회차 완료 숫자는 읽지 않는다. 같은 순간에 다음 구간 안내("1세트 완료, 휴식 1분 30초")가 나오기 때문이다.
- 진행 화면에는 **현재 회차 / 목표 횟수**를 크게 표시하고, 1회 안에서 지난 시간을 진행 바로 보여준다.

## 4. 프리셋

프리셋은 수정할 수 없다. "복사해서 수정"하면 커스텀 루틴으로 저장된다.

| 프리셋 | 종료 조건 | 준비 | 운동 | 휴식 | 라운드 | 세트 | 세트 간 휴식 | 마지막 라운드 휴식 건너뛰기 |
|---|---|---|---|---|---|---|---|---|
| 타바타 | 시간 | 10초 | 20초 | 10초 | 8 | 1 | - | 켜짐 |
| HIIT | 시간 | 10초 | 40초 | 20초 | 8 | 1 | - | 켜짐 |
| 플랭크 | 시간 | 10초 | 30초 | 30초 | 3 | 1 | - | 켜짐 |
| 근력 세트 | 횟수 (15회, 1회 3초) | 10초 | 15회 | 90초 | 3 | 1 | - | 켜짐 |

- 근력 세트는 01 문서에 있던 "세트 휴식 타이머"를 대체한다. 화면에는 `15회 × 3세트, 세트 간 휴식 90초`로 표시한다(2.5절). 목표 횟수는 12회에서 15회로 바꿨다 (2026-11-19). 휴식이 끝나면 다음 세트가 자동으로 시작되므로 화면을 누를 필요가 없다.

## 5. 진행 중 조작

| 조작 | 동작 |
|---|---|
| 일시정지 / 재개 | 시간과 박자를 멈춘다. 횟수 모드에서 재개하면 **현재 회차를 처음부터** 다시 진행한다 |
| 다음 구간 | 현재 구간을 끝내고 다음 구간으로 넘어간다. 횟수 모드의 운동 구간에서는 버튼 이름을 **"세트 완료"**로 표시한다 |
| 이전 구간 | 현재 구간이 3초 넘게 지났으면 현재 구간을 처음부터 다시 한다. 3초 이내라면 이전 구간으로 돌아간다 |
| 휴식 +10초 | 휴식과 세트 간 휴식 구간에서만 보인다. 누를 때마다 10초씩 늘어난다 |
| 중단 | 일시정지한 뒤 확인 창("운동을 끝낼까요?")을 띄운다. 확인하면 결과 화면으로 간다 |

- 진행 화면 버튼은 장갑을 끼거나 손에 땀이 나도 누를 수 있게 크게 만든다. 크기는 03 화면 설계에서 정한다.

## 6. 알림 규칙

### 6.1 시간 모드

| 시점 | 소리 | 진동 | 음성 |
|---|---|---|---|
| 준비 시작 | - | - | "준비하세요" |
| 각 구간 종료 3·2·1초 전 | 짧은 비프 | 짧게 | "3, 2, 1" |
| 운동 시작 | 긴 비프 | 길게 | "운동 시작" |
| 운동 구간 절반 (60초 이상일 때만) | - | - | "절반 지났습니다" |
| 휴식 시작 | 긴 비프 | 길게 | "휴식 20초" (설정 시간을 읽어줌) |
| 휴식 종료 10초 전 (휴식 20초 이상일 때만) | - | - | "10초 남았습니다" |
| 새 라운드 시작 | - | - | "3라운드" (운동 시작 안내 앞에 붙임) |
| 세트 간 휴식 시작 | 긴 비프 | 길게 | "1세트 완료, 휴식 1분" |
| 루틴 완료 | 완료음 | 길게 2번 | "운동 완료. 총 12분 30초" |

### 6.2 횟수 모드

- 운동 구간은 3.3절 규칙을 따른다.
- 표시 규칙(2.5절)에 따라 휴식은 "세트 간 휴식"으로 안내하고, 다음 세트와 횟수를 붙인다. 예: "1세트 완료, 휴식 1분 30초, 다음 2세트 12회" (세트가 하나면 "다음 12회")
- 휴식 종료 10초 전 안내, 3·2·1 카운트다운, 완료 안내는 6.1과 같다.
- 카운트다운 다음에는 음성 없이 긴 비프로 시작한다 (3.3절).

### 6.3 알림 설정 (앱 전체 기본값)

| 항목 | 선택지 | 기본값 |
|---|---|---|
| 소리 | 켜짐 / 꺼짐 | 켜짐 |
| 진동 | 켜짐 / 꺼짐 | 켜짐 |
| 음성 안내 | 켜짐 / 꺼짐 | 켜짐 |
| 종료 전 카운트다운 | 없음 / 3초 / 5초 | 3초 |
| 음성 속도 | 느리게 / 보통 / 빠르게 | 보통 |

### 6.4 음성 안내: 기기 TTS

음성 안내는 **기기에 설치된 TTS(Text-to-Speech) 엔진만** 사용한다. 녹음 음성은 쓰지 않는다. (2026-11-18 결정)

- 구현: Flutter `flutter_tts` 패키지로 Android 기본 TTS 엔진(보통 Google 음성 엔진)을 호출한다.
- 언어: 앱 언어(6.6절)와 같은 언어로 읽는다. 한국어는 `ko-KR`, 영어는 `en-US`.
- **그 언어의 음성이 없거나 TTS를 쓸 수 없는 기기**
  - 앱을 처음 실행할 때와 음성 안내를 켤 때 사용할 수 있는지 확인한다.
  - 쓸 수 없으면 설정 화면에 "설치 필요"라고 알리고, 기기 TTS 설정 화면으로 가는 버튼을 보여준다.
  - 이 경우 음성 안내 없이 비프음과 진동만으로 진행한다. 타이머는 멈추지 않는다.
- **타이밍**
  - 안내 문장은 미리 만들어 두고, 구간이 시작될 때 지연 없이 바로 재생한다.
  - 앞 안내가 끝나기 전에 다음 안내가 오면 앞 안내를 끊고 새 안내를 재생한다. 박자와 회차가 실제 진행보다 늦어지지 않게 하기 위해서다.
  - 템포가 빠를 때(1회 2초 이하)는 회차 숫자만 짧게 읽는다. 예: "열둘"
- 숫자 읽기 (한국어): 회차는 고유어 수사("하나, 둘 … 열둘")로 읽고, 시간은 한자어로 읽는다("1분 30초", "10초 남았습니다"). TTS가 숫자 "1"을 "일"로 읽기 때문에 회차는 글자로 바꿔 넣는다.
- 숫자 읽기 (영어): 회차는 숫자 그대로 넘긴다 ("1", "2" …). 시간은 "1 minute 30 seconds"처럼 읽는다.
- 음성 속도 설정(6.3절)은 TTS 말하기 속도에 그대로 적용한다.

### 6.6 언어 (2026-11-20 추가)

- 지원 언어: 한국어, 영어.
- 처음 실행할 때 언어를 묻지 않는다. **휴대폰 언어를 따르고**, 지원하지 않는 언어면 영어로 시작한다.
- 설정에서 "기기 언어 따르기 / 한국어 / English" 중에서 바꿀 수 있다. 고른 언어는 저장되어 다음 실행에도 쓴다.
- Android 13 이상에서는 휴대폰 설정 > 앱 > 언어(앱별 언어)와 같은 값을 쓴다. 어느 쪽에서 바꿔도 같은 결과가 나온다.
- 화면 문구, 알림 영역, 음성 안내가 모두 같은 언어를 쓴다.
- 프리셋 이름은 언어에 맞춰 보여준다 (예: 플랭크 / Plank). 사용자가 만든 루틴·코스 이름은 그대로 둔다.

### 6.5 소리 출력 규칙

- 안내음과 음성은 **미디어 볼륨**으로 재생한다. 그래서 무음 모드에서도 이어폰으로 들린다. (Android 실제 동작 확인 필요)
- 다른 앱의 음악이 재생 중이면 안내가 나오는 동안만 음악 볼륨을 줄였다가 되돌린다 (audio ducking).
- 진동은 기기의 진동 설정을 따른다.

## 7. 백그라운드 동작

- 타이머가 진행되는 동안에는 **포그라운드 서비스**로 동작한다. 화면이 꺼지거나 다른 앱을 써도 타이머, 소리, 음성이 계속된다.
- **알림 영역 표시**
  - 내용: 현재 구간 이름, 남은 시간 또는 `현재 회차/목표 횟수`, 진행 위치 (시간 모드 `라운드 3/8 · 세트 1/2`, 횟수 모드 `세트 2/3`)
  - 버튼: 일시정지/재개, 다음 구간
- **화면 꺼짐 방지**: 진행 화면이 열려 있는 동안 화면이 꺼지지 않게 한다. 설정에서 끌 수 있고 기본값은 켜짐이다.
- **비정상 종료 시**: 진행 상태(루틴, 현재 구간, 경과 시간)를 주기적으로 저장한다. 다음에 앱을 열면 "진행 중이던 운동을 이어서 할까요?"라고 묻는다. 저장 후 30분이 지난 상태는 버린다.

## 8-1. 코스 (2026-11-20 추가)

루틴 여러 개를 하나로 묶어 연달아 진행한다. 예: `타바타 → 휴식 1분 → 근력 세트 → 휴식 없음 → 플랭크`

**이름**: "코스". 앱 안에서 이미 "세트", "라운드", "루틴"을 쓰고 있어서 겹치지 않고, "정해진 순서대로 거쳐 가는 것"이라는 뜻이 바로 전달된다. 서킷(circuit)은 같은 묶음을 여러 바퀴 도는 뜻이 강해서 쓰지 않았다.

### 구성

| 항목 | 내용 |
|---|---|
| 이름 | 1~20자 |
| 루틴 목록 | **내 루틴** 중에서 골라 조합한다 (프리셋은 넣지 않는다). 내 루틴이 하나도 없으면 코스를 만들 수 없다. 같은 루틴을 여러 번 넣어도 된다. 1~20개 |
| 루틴 사이 휴식 | 루틴과 루틴 사이마다 따로 정한다. 기본 1분, 0초(휴식 없음) ~ 30분. 마지막 루틴 뒤에는 없다 |

- 코스는 루틴을 **가리키기만** 한다. 루틴을 고치면 코스에도 바로 반영된다.
- 코스에 들어간 루틴을 지우면 그 코스에서도 빠진다. 지울 때 확인 창에 "이 루틴이 들어간 코스 N개에서도 빠져요"라고 알린다.
- 코스를 지워도 안에 있던 루틴은 지워지지 않는다.

### 진행 규칙

- 코스 전체를 **한 번의 운동**으로 진행한다. 구간 목록을 이어 붙여 엔진 하나가 처음부터 끝까지 돌린다.
- **준비 구간**은 첫 루틴 것만 쓴다. 두 번째 루틴부터는 준비 없이 시작한다.
- 각 루틴 끝의 휴식은 원래대로 빠지고, 그 자리에 **루틴 사이 휴식**이 들어간다.
  - 휴식이 있으면: `휴식 1분, 다음은 스쿼트` 안내 → 10초 전 안내 → 카운트다운 → 다음 루틴 시작. `+10초`도 쓸 수 있다.
  - 휴식이 없으면: 앞 루틴이 끝나자마자 다음 루틴 첫 운동을 시작한다.
- 각 루틴의 첫 운동을 시작할 때 루틴 이름을 먼저 읽는다. 예: `플랭크, 운동 시작`
  - 횟수 모드 루틴은 운동 시작에 음성이 없으므로(3.3절) 준비 구간이나 루틴 사이 휴식에서 이름과 횟수를 읽는다. 예: `준비하세요, 스쿼트, 1세트 15회`, `휴식 1분, 다음은 스쿼트, 1세트 15회`. 루틴 사이 휴식이 없으면 이름을 읽지 않는다.
- 템포, 음성 안내 방식, 휴식 같은 설정은 **각 루틴의 설정을 그대로** 쓴다.
- 이전/다음은 구간 단위로 움직이며 루틴 경계를 넘을 수 있다.
- 무료 운동은 코스 하나를 1회로 센다 (10.2절).
- 이어하기(7장)는 코스에서도 된다. 확인 창에 `아침 코스 · 2/3 스쿼트 · 세트 1/3`처럼 위치를 보여준다.

### 관리

| 기능 | 내용 |
|---|---|
| 만들기 | 홈 맨 아래 "새로 만들기" 버튼 → "코스" |
| 수정 / 복사해서 수정 / 삭제 | 코스 메뉴에서. 삭제할 때 확인 창 |
| 정렬 | 내 루틴과 같은 4가지(직접 정렬 / 최근 사용순 (기본) / 이름순 / 만든 순)를 내 루틴과 따로 고른다. 길게 눌러 순서를 바꾸면 "직접 정렬"로 바뀐다 |
| 즐겨찾기, 최근 카드 | 이번에는 넣지 않는다. 쓰임새를 보고 결정 |
| 저장 위치 | 루틴과 같은 `routines.json` |

## 9. 결과 화면

루틴이 끝나거나 중단하면 다음을 보여준다.
- 총 경과 시간, 완료한 라운드/세트 수 (횟수 모드는 세트 수만)
- 횟수 모드: 총 횟수 (예: `12회 × 3세트 = 36회`)
- 버튼: 다시 하기, 홈으로

> 결과를 기록으로 저장하는 기능은 2차(운동 기록)에서 다룬다.

## 10. 무료 체험과 정식 버전 구매

광고는 쓰지 않는다. 무료 체험 후 한 번 구매로 정식 버전을 연다 (01 문서 7장).

### 10.1 이용 상태

| 상태 | 조건 | 쓸 수 있는 기능 |
|---|---|---|
| 체험 중 | 무료 운동 횟수가 남아 있음 | 모든 기능 |
| 체험 종료 | 무료 운동 15회를 다 씀, 구매 안 함 | 프리셋 실행, 설정. 내 루틴은 목록에 보이지만 잠김 |
| 정식 버전 | 구매 완료 | 모든 기능, 제한 없음 |

### 10.2 무료 운동 횟수 세기

- 무료 운동은 **15회**다.
- 루틴을 시작하고 **60초 이상 진행**하면 1회를 쓴다. 60초가 되는 순간 차감한다.
  - 60초 전에 중단하면 세지 않는다. 시험 삼아 눌러본 것까지 세지 않기 위해서다.
  - 일시정지한 시간은 진행 시간에 넣지 않는다.
- 프리셋과 내 루틴 모두 센다.
- **운동 중에는 절대 막지 않는다.** 진행 중에 마지막 무료 횟수를 쓰더라도 그 운동은 끝까지 진행된다.
- 정식 버전을 사면 더 이상 세지 않는다.

### 10.3 체험 종료 후 잠기는 것

| 기능 | 체험 종료 후 |
|---|---|
| 프리셋 실행 | 무료 |
| 설정 | 무료 |
| 내 루틴 실행 | 잠김 → 결제 화면 |
| 새 루틴 만들기 ("새로 만들기" 버튼) | 잠김 → 결제 화면 |
| 코스 만들기·수정·실행 | 잠김 → 결제 화면 (내 루틴으로 만드는 기능) |
| 코스 삭제 | 가능 |
| 내 루틴 수정, 프리셋 "복사해서 수정" | 잠김 → 결제 화면 |
| 내 루틴 삭제, 즐겨찾기 | 가능 |
| 이미 만든 내 루틴 | **지우지 않는다.** 잠금 표시와 함께 목록에 남긴다. 구매하면 바로 쓸 수 있다 |
| 이어하기 (D1) | 잠긴 루틴이면 이어하지 않고 버린다 |

### 10.4 구매 안내 시점

구매를 권하는 화면을 갑자기 띄우지 않는다. 사용자가 잠긴 기능을 누르거나 운동을 마쳤을 때만 안내한다.

| 시점 | 안내 |
|---|---|
| 항상 (체험 중) | 홈 앱바에 작은 배지 "무료 N회". 체험 종료 후에는 같은 자리에 "정식 버전" 배지 (03 문서 3장) |
| 운동 완료 후 남은 횟수가 5·3·1회일 때 | 결과 화면 아래에 한 줄 안내 + "정식 버전 보기" 링크 |
| 마지막 무료 운동을 마쳤을 때 | 결과 화면에 체험 종료 카드 + 구매 버튼. 프리셋은 계속 무료라는 점을 함께 알림 |
| 체험 종료 후 잠긴 기능을 눌렀을 때 | 결제 화면 (03 문서 S6) |
| 설정 | "정식 버전" 항목에서 언제든 구매·복원 |

### 10.5 결제

- Google Play 인앱 결제의 **비소모성 상품**(한 번 사면 계속 유지되는 상품)으로 판매한다. Flutter `in_app_purchase` 패키지를 쓴다.
- 상품 ID: `fitness_timer` (Play Console에 등록, 바꿀 수 없음)
- 구매 옵션: ID `lifetime`, 구매(Buy) 방식, 태그 `full-version`. 이전 버전과 호환되는 옵션으로 지정
- 가격: **₩5,900** (부가세 포함), 미국 **$3.99**. 나머지 나라는 Play가 환율로 정한 가격을 쓴다 (2026-11-20)
- **구매 복원**: 앱을 실행할 때마다 Google Play에서 구매 내역을 확인한다. 같은 Google 계정이면 앱을 다시 설치하거나 기기를 바꿔도 정식 버전이 유지된다. 설정과 결제 화면에도 "구매 복원" 버튼을 둔다.
- **오프라인**: 마지막으로 확인한 구매 상태를 기기에 저장해 두고, 인터넷이 없을 때는 그 값을 쓴다.
- **환불**: Google Play에서 환불되어 구매 내역이 사라지면, 다음 확인 때 체험 종료 상태로 돌아간다.
- 영수증 서버 검증은 MVP에서 하지 않는다 (서버 없음). 불법 복제 위험은 감수한다.

### 10.6 알려진 한계

- 무료 운동 횟수는 기기 안에만 저장한다. 앱을 지우고 다시 설치하면 체험이 처음부터 다시 시작될 수 있다. 금액이 크지 않은 앱이라 MVP에서는 감수한다.
