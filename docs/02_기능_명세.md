# 02. 기능 명세

| 항목 | 내용 |
|---|---|
| 대상 범위 | MVP (Android 1차 출시) |
| 관련 문서 | [01. 서비스 개요](01_서비스_개요.md) |
| 문서 상태 | 초안 (2026-11-18) |

## 1. 용어

| 용어 | 뜻 |
|---|---|
| 루틴 | 사용자가 시작하는 타이머 한 묶음. 프리셋 또는 직접 만든 루틴 |
| 구간 | 타이머가 진행하는 가장 작은 단위. 준비 / 운동 / 휴식 / 세트 간 휴식 |
| 라운드 | `운동 → 휴식` 한 번 |
| 세트 | 라운드를 정해진 횟수만큼 반복한 묶음 |
| 시간 모드 | 운동 구간이 **시간**으로 끝남 (예: 40초) |
| 횟수 모드 | 운동 구간이 **횟수**로 끝남 (예: 12회). 앱이 템포에 맞춰 횟수를 세어줌 |
| 템포 | 횟수 모드에서 1회 동작에 걸리는 시간 구성 (내려가기 / 멈춤 / 올라오기) |

## 2. 루틴 구조

```
준비
└ 세트 × N
   ├ 라운드 × M
   │   ├ 운동 (시간 또는 횟수)
   │   └ 휴식
   └ 세트 간 휴식
완료
```

### 2.1 설정 항목

| 항목 | 범위 | 단위 | 기본값 | 비고 |
|---|---|---|---|---|
| 루틴 이름 | 1~20자 | - | "내 루틴" | |
| 준비 시간 | 0~60초 | 1초 | 10초 | 0이면 준비 구간 없음 |
| 운동 종료 조건 | 시간 / 횟수 | - | 시간 | 3장 참고 |
| 운동 시간 (시간 모드) | 5초~99분 59초 | 1초 | 40초 | |
| 목표 횟수 (횟수 모드) | 1~100회 | 1회 | 12회 | |
| 템포 (횟수 모드) | 3.2절 참고 | | 2-0-1 | |
| 휴식 시간 | 0초~99분 59초 | 1초 | 20초 | 0이면 휴식 구간 없음 |
| 라운드 수 | 1~99 | 1 | 8 | |
| 세트 수 | 1~20 | 1 | 1 | 시간 모드에서만 사용 (2.5절) |
| 세트 간 휴식 | 0초~30분 | 5초 | 60초 | 세트 수가 1이거나 횟수 모드면 숨김 |
| 마지막 라운드 휴식 건너뛰기 | 켜짐 / 꺼짐 | - | 켜짐 | 2.2절 참고 |

### 2.2 구간 경계 규칙

- **마지막 라운드 휴식 건너뛰기** (루틴별 설정)
  - 켜짐: 세트의 마지막 라운드가 끝나면 휴식 없이 바로 **세트 간 휴식**으로 넘어간다. 마지막 세트라면 **완료**로 넘어간다.
  - 꺼짐: 마지막 라운드 뒤에도 휴식을 진행한 다음 세트 간 휴식으로 넘어간다.
- **마지막 세트 뒤의 세트 간 휴식**은 항상 건너뛰고 완료로 간다.
- 시간이 0으로 설정된 구간은 만들지 않는다. 안내 음성도 나오지 않는다.

### 2.3 실행 순서 예시

`준비 10초 / 운동 20초 / 휴식 10초 × 3라운드 × 2세트 / 세트 간 휴식 60초`, 마지막 라운드 휴식 건너뛰기 **켜짐**:

```
준비10 → 운동20 → 휴식10 → 운동20 → 휴식10 → 운동20
       → 세트간휴식60
       → 운동20 → 휴식10 → 운동20 → 휴식10 → 운동20 → 완료
```

### 2.4 예상 소요 시간

루틴 목록과 편집 화면에 **예상 총 시간**을 표시한다.
- 시간 모드: 모든 구간 시간의 합
- 횟수 모드: 운동 구간 시간 = `목표 횟수 × 1회 시간` (3.2절)

### 2.5 횟수 모드의 "세트" 표시

웨이트 사용자에게 익숙한 용어를 쓰기 위해, 횟수 모드에서는 **라운드를 "세트"라고 표시**한다.

| 내부 구조 | 시간 모드 표시 | 횟수 모드 표시 |
|---|---|---|
| 라운드 | 라운드 | **세트** |
| 라운드 사이 휴식 | 휴식 | **세트 간 휴식** |
| 세트 (바깥 반복) | 세트 | 사용하지 않음 (세트 수 1로 고정, 편집 화면에서 숨김) |

- 예: 횟수 모드 루틴 `12회 × 3세트, 세트 간 휴식 90초`는 내부적으로 `12회 → 휴식 90초 × 3라운드 × 1세트`이다.
- 편집 화면, 진행 화면, 알림 영역, 음성 안내, 결과 화면 모두 이 표시 규칙을 따른다.
- 시간 모드 루틴을 횟수 모드로 바꾸면, 세트 수가 2 이상인 경우 "세트 반복 설정이 사라집니다"라고 확인을 받고 세트 수를 1로 바꾼다.

## 3. 운동 종료 조건: 시간 / 횟수

| 종료 조건 | 사용하는 경우 | 대표 운동 |
|---|---|---|
| 시간 | 정해진 시간 동안 하는 운동 | 타바타, HIIT, 플랭크 |
| 횟수 | 정해진 횟수를 채우는 운동 | 스쿼트, 푸시업, 런지, 덤벨 컬 등 근력 운동 |

종료 조건은 루틴 단위로 정한다. 한 루틴 안의 운동 구간은 모두 같은 조건을 쓴다.

### 3.1 횟수 모드: 템포 가이드 방식

앱이 정해진 템포에 맞춰 소리와 음성으로 박자를 알려주면, 사용자가 그 박자에 맞춰 동작한다. 목표 횟수를 채우면 다음 구간으로 자동으로 넘어간다.

- 센서와 카메라를 쓰지 않는다. 그래서 화면이 꺼져 있거나 이어폰만 쓸 때도 똑같이 동작한다.
- 실제 동작을 감지하지는 않는다. 사용자가 박자를 놓치면 일시정지하거나 "세트 완료"로 직접 끝낸다(5장).

> 검토 후 제외한 방식: 수동 탭 입력(운동 중 폰 조작 필요), 가속도 센서(폰 위치에 따라 오차 큼), 카메라 자세 인식(화면 켜짐·거치 필요). → 2026-11-18 결정

### 3.2 템포 설정

1회 동작 = **내려가기 → 멈춤 → 올라오기**

| 항목 | 범위 | 단위 | 기본값 |
|---|---|---|---|
| 내려가기 | 0.5~5초 | 0.5초 | 2초 |
| 멈춤 (가장 구부린 상태) | 0~5초 | 0.5초 | 0초 |
| 올라오기 | 0.5~5초 | 0.5초 | 1초 |

- 표기: `내려가기-멈춤-올라오기` (예: `2-0-1`)
- 1회 시간 = 세 값의 합 (기본 3초)
- 빠른 선택 버튼: **천천히 3-1-2** / **보통 2-0-1** / **빠르게 1-0-1**

### 3.3 횟수 모드 진행

| 시점 | 소리 | 음성 (안내 방식 "숫자만" 기준) |
|---|---|---|
| 운동 구간 시작 | 긴 비프 | "12회 시작" |
| 내려가기 시작 | 낮은 비프 | - |
| 멈춤 시작 | 짧은 틱 | - |
| 올라오기 시작 | 높은 비프 | - |
| 1회 완료 | - | 회차 숫자 ("하나", "둘" … "열둘") |
| 남은 횟수 3회 | - | 숫자 대신 "마지막 3회" (목표 횟수 6회 이상일 때만) |
| 목표 횟수 달성 | 완료음 | "완료" → 다음 구간으로 |

- **안내 방식** (루틴별 선택)
  - 숫자만 (기본): 동작 전환은 비프음으로, 회차는 음성으로 알린다
  - 동작 + 숫자: "내려가고", "올라오고"까지 음성으로 알린다. 템포가 느린 초보자용이며, 1회 시간이 2.5초 미만이면 선택할 수 없다
  - 비프만: 음성 없이 비프음만 쓴다
- 진행 화면에는 **현재 회차 / 목표 횟수**를 크게 표시하고, 현재 동작(내려가기·멈춤·올라오기)을 색과 진행 바로 보여준다.

## 4. 프리셋

프리셋은 수정할 수 없다. "복사해서 수정"하면 커스텀 루틴으로 저장된다.

| 프리셋 | 종료 조건 | 준비 | 운동 | 휴식 | 라운드 | 세트 | 세트 간 휴식 | 마지막 라운드 휴식 건너뛰기 |
|---|---|---|---|---|---|---|---|---|
| 타바타 | 시간 | 10초 | 20초 | 10초 | 8 | 1 | - | 켜짐 |
| HIIT | 시간 | 10초 | 40초 | 20초 | 8 | 1 | - | 켜짐 |
| 플랭크 | 시간 | 10초 | 30초 | 30초 | 3 | 1 | - | 켜짐 |
| 근력 세트 | 횟수 (12회, 2-0-1) | 10초 | 12회 | 90초 | 3 | 1 | - | 켜짐 |

- 근력 세트는 01 문서에 있던 "세트 휴식 타이머"를 대체한다. 화면에는 `12회 × 3세트, 세트 간 휴식 90초`로 표시한다(2.5절). 휴식이 끝나면 다음 세트가 자동으로 시작되므로 화면을 누를 필요가 없다.

## 5. 진행 중 조작

| 조작 | 동작 |
|---|---|
| 일시정지 / 재개 | 시간과 박자를 멈춘다. 횟수 모드에서 재개하면 **현재 회차를 처음(내려가기)부터** 다시 진행한다 |
| 다음 구간 | 현재 구간을 끝내고 다음 구간으로 넘어간다. 횟수 모드의 운동 구간에서는 버튼 이름을 **"세트 완료"**로 표시한다 |
| 이전 구간 | 현재 구간이 3초 넘게 지났으면 현재 구간을 처음부터 다시 한다. 3초 이내라면 이전 구간으로 돌아간다 |
| 휴식 +10초 | 휴식과 세트 간 휴식 구간에서만 보인다. 누를 때마다 10초씩 늘어난다 |
| 중단 | 일시정지한 뒤 확인 창("운동을 끝낼까요?")을 띄운다. 확인하면 결과 화면으로 간다 |

- 진행 화면 버튼은 장갑을 끼거나 손에 땀이 나도 누를 수 있게 크게 만든다. 크기는 03 화면 설계에서 정한다.

## 6. 알림 규칙

### 6.1 시간 모드

| 시점 | 소리 | 진동 | 음성 |
|---|---|---|---|
| 준비 시작 | - | - | "준비하세요" |
| 각 구간 종료 3·2·1초 전 | 짧은 비프 | 짧게 | "3, 2, 1" |
| 운동 시작 | 긴 비프 | 길게 | "운동 시작" |
| 운동 구간 절반 (60초 이상일 때만) | - | - | "절반 지났습니다" |
| 휴식 시작 | 긴 비프 | 길게 | "휴식 20초" (설정 시간을 읽어줌) |
| 휴식 종료 10초 전 (휴식 20초 이상일 때만) | - | - | "10초 남았습니다" |
| 새 라운드 시작 | - | - | "3라운드" (운동 시작 안내 앞에 붙임) |
| 세트 간 휴식 시작 | 긴 비프 | 길게 | "1세트 완료, 휴식 1분" |
| 루틴 완료 | 완료음 | 길게 2번 | "운동 완료. 총 12분 30초" |

### 6.2 횟수 모드

- 운동 구간은 3.3절 규칙을 따른다.
- 표시 규칙(2.5절)에 따라 휴식은 "세트 간 휴식"으로 안내한다. 예: "1세트 완료, 휴식 1분 30초"
- 휴식 종료 10초 전 안내, 3·2·1 카운트다운, 완료 안내는 6.1과 같다.
- 카운트다운 다음에는 "2세트, 12회 시작"이라고 안내한다.

### 6.3 알림 설정 (앱 전체 기본값)

| 항목 | 선택지 | 기본값 |
|---|---|---|
| 소리 | 켜짐 / 꺼짐 | 켜짐 |
| 진동 | 켜짐 / 꺼짐 | 켜짐 |
| 음성 안내 | 켜짐 / 꺼짐 | 켜짐 |
| 종료 전 카운트다운 | 없음 / 3초 / 5초 | 3초 |
| 음성 속도 | 느리게 / 보통 / 빠르게 | 보통 |

### 6.4 음성 안내: 기기 TTS

음성 안내는 **기기에 설치된 TTS(Text-to-Speech) 엔진만** 사용한다. 녹음 음성은 쓰지 않는다. (2026-11-18 결정)

- 구현: Flutter `flutter_tts` 패키지로 Android 기본 TTS 엔진(보통 Google 음성 엔진)을 호출한다.
- 언어: 한국어(`ko-KR`) 음성을 사용한다.
- **한국어 음성이 없거나 TTS를 쓸 수 없는 기기**
  - 앱을 처음 실행할 때와 음성 안내를 켤 때 사용할 수 있는지 확인한다.
  - 쓸 수 없으면 "한국어 음성이 설치되어 있지 않습니다"라고 알리고, 기기 TTS 설정 화면으로 가는 버튼을 보여준다.
  - 이 경우 음성 안내 없이 비프음과 진동만으로 진행한다. 타이머는 멈추지 않는다.
- **타이밍**
  - 안내 문장은 미리 만들어 두고, 구간이 시작될 때 지연 없이 바로 재생한다.
  - 앞 안내가 끝나기 전에 다음 안내가 오면 앞 안내를 끊고 새 안내를 재생한다. 박자와 회차가 실제 진행보다 늦어지지 않게 하기 위해서다.
  - 템포가 빠를 때(1회 2초 이하)는 회차 숫자만 짧게 읽는다. 예: "열둘"
- 숫자 읽기: 회차는 고유어 수사("하나, 둘 … 열둘")로 읽고, 시간은 한자어로 읽는다("1분 30초", "10초 남았습니다").
- 음성 속도 설정(6.3절)은 TTS 말하기 속도에 그대로 적용한다.

### 6.5 소리 출력 규칙

- 안내음과 음성은 **미디어 볼륨**으로 재생한다. 그래서 무음 모드에서도 이어폰으로 들린다. (Android 실제 동작 확인 필요)
- 다른 앱의 음악이 재생 중이면 안내가 나오는 동안만 음악 볼륨을 줄였다가 되돌린다 (audio ducking).
- 진동은 기기의 진동 설정을 따른다.

## 7. 백그라운드 동작

- 타이머가 진행되는 동안에는 **포그라운드 서비스**로 동작한다. 화면이 꺼지거나 다른 앱을 써도 타이머, 소리, 음성이 계속된다.
- **알림 영역 표시**
  - 내용: 현재 구간 이름, 남은 시간 또는 `현재 회차/목표 횟수`, 진행 위치 (시간 모드 `라운드 3/8 · 세트 1/2`, 횟수 모드 `세트 2/3`)
  - 버튼: 일시정지/재개, 다음 구간
- **화면 꺼짐 방지**: 진행 화면이 열려 있는 동안 화면이 꺼지지 않게 한다. 설정에서 끌 수 있고 기본값은 켜짐이다.
- **비정상 종료 시**: 진행 상태(루틴, 현재 구간, 경과 시간)를 주기적으로 저장한다. 다음에 앱을 열면 "진행 중이던 운동을 이어서 할까요?"라고 묻는다. 저장 후 30분이 지난 상태는 버린다.

## 8. 루틴 관리

| 기능 | 내용 |
|---|---|
| 만들기 | 빈 루틴에서 시작하거나, 프리셋이나 기존 루틴을 복사해서 시작 |
| 수정 / 삭제 | 커스텀 루틴만 가능. 삭제할 때 확인 창을 띄움 |
| 즐겨찾기 | 즐겨찾기한 루틴을 첫 화면 위쪽에 고정 |
| 정렬 | 최근 사용순 (기본) / 이름순 / 만든 순 |
| 저장 개수 | MVP는 제한 없음. 수익 모델이 확정되면 다시 검토 |
| 저장 위치 | 기기 내부 저장소 (백업/복원은 3차) |

## 9. 결과 화면

루틴이 끝나거나 중단하면 다음을 보여준다.
- 총 경과 시간, 완료한 라운드/세트 수 (횟수 모드는 세트 수만)
- 횟수 모드: 총 횟수 (예: `12회 × 3세트 = 36회`)
- 버튼: 다시 하기, 홈으로

> 결과를 기록으로 저장하는 기능은 2차(운동 기록)에서 다룬다.
