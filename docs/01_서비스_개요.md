# 01. 서비스 개요

| 항목 | 내용 |
|---|---|
| 앱 이름 | Fitness Timer (2026-11-19 변경, 이전 이름 Health Timer) |
| 한 줄 소개 | 운동 중에 화면을 보지 않아도 되는 피트니스 운동 타이머 |
| 플랫폼 | Flutter, Android 먼저 출시 → iOS |
| 벤치마크 | 타이머 플러스 (Timer Plus) |
| 문서 상태 | 초안 (2026-11-18) |

## 1. 배경과 문제

운동할 때 쓰는 기본 시계/타이머 앱은 "시간 한 번 재기"에 맞춰져 있어 운동에는 불편하다.

- **반복 구조를 표현하지 못함**: 운동은 `운동 40초 → 휴식 20초 × 8라운드 × 3세트`처럼 반복되는데, 기본 타이머는 매번 다시 맞춰야 한다.
- **화면을 볼 수 없음**: 바벨을 들거나 매트 위에 있을 때 폰을 확인하기 어렵다. 소리·진동·음성으로 알려줘야 한다.
- **세트 간 휴식 관리가 번거로움**: 웨이트 트레이닝에서는 세트가 끝날 때마다 휴식 타이머를 다시 눌러야 한다.
- **자주 쓰는 루틴을 저장할 수 없음**: 같은 루틴을 매번 새로 입력해야 한다.

## 2. 서비스 목표

1. 운동 중 **폰을 만지거나 보지 않아도** 루틴을 끝까지 진행할 수 있다.
2. 자주 하는 운동 방식(인터벌, 타바타, 세트 휴식 등)을 **3번 이내 터치로 시작**할 수 있다.
3. 직접 만든 루틴을 **저장하고 다시 쓸** 수 있다.

## 3. 타깃 사용자

| 구분 | 사용자 | 주요 니즈 |
|---|---|---|
| 핵심 | 홈트레이닝 사용자 | 타바타·HIIT 루틴을 쉽게 시작하고 음성 안내를 받고 싶다 |
| 핵심 | 헬스장 웨이트 사용자 | 세트 간 휴식 시간을 정확히 지키고 싶다 |
| 확장 | 크로스핏/서킷 운동 사용자 | EMOM, AMRAP 등 정해진 형식의 타이머가 필요하다 |
| 확장 | 러닝·스트레칭 사용자 | 구간 반복, 동작별 유지 시간 안내가 필요하다 |

### 대표 시나리오
- **A. 홈트 (타바타)**: 거실 매트에 폰을 세워두고 "타바타" 프리셋을 누른다. 시작 전 10초 카운트다운 후 운동/휴식 전환을 음성과 비프음으로 듣는다. 끝나면 총 운동 시간을 확인한다.
- **B. 헬스장 (세트 휴식)**: 벤치프레스 한 세트를 끝내고 화면을 한 번 누르면 90초 휴식 타이머가 시작된다. 이어폰으로 종료 10초 전 알림을 듣는다. 폰이 잠겨 있어도 알림이 온다.

## 4. 벤치마크: 타이머 플러스

> 아래는 운동 타이머 앱에서 흔히 볼 수 있는 기능을 기준으로 정리한 가설이다. **실제 앱을 설치해서 확인한 뒤 보완해야 한다.**

| 구분 | 확인할 항목 |
|---|---|
| 참고할 점 | 운동/휴식/라운드/세트를 조합하는 커스텀 루틴 구조 |
| 참고할 점 | 큰 숫자와 구간별 색상으로 멀리서도 상태가 보이는 진행 화면 |
| 참고할 점 | 구간 전환 시 소리·진동·음성 안내 |
| 참고할 점 | 백그라운드·잠금 화면에서도 계속 동작 |
| 확인 필요 | 광고 노출 위치와 빈도, 유료 기능 범위와 가격 |
| 확인 필요 | 사용자 리뷰에서 반복되는 불만 (스토어 리뷰 분석) |

### 차별화 방향 (가설)
- **시작까지 걸리는 시간 최소화**: 첫 화면에서 최근/즐겨찾는 루틴을 바로 시작
- **광고 없는 앱**: 광고 대신 무료 체험 후 한 번 구매하는 방식. 운동 흐름을 끊는 요소가 없음
- **한국어 음성 안내 품질**: 자연스러운 한국어 안내 ("휴식 10초 남았습니다")
- **웨이트 사용자를 위한 세트 휴식 모드**: 인터벌 앱에서 약한 부분을 보강

## 5. 기능 범위

### MVP (Android 1차 출시)
| 기능 | 설명 |
|---|---|
| 프리셋 타이머 | 타바타, 인터벌(HIIT), 플랭크 (시간 기준) / 근력 세트 (횟수 기준) |
| 횟수 모드 | 운동 구간을 횟수로 진행. 템포(내려가기-멈춤-올라오기)에 맞춰 앱이 박자와 회차를 안내 |
| 커스텀 루틴 | 준비 / 운동(시간 또는 횟수) / 휴식 / 라운드 수 / 세트 수 / 세트 간 휴식 / 마지막 라운드 휴식 건너뛰기 설정 |
| 루틴 저장 | 루틴 저장·수정·삭제, 즐겨찾기 |
| 진행 화면 | 큰 남은 시간, 구간별 색상, 현재 라운드/세트, 일시정지·건너뛰기 |
| 알림 | 비프음, 진동, 한국어 음성 안내, 종료 전 카운트다운 |
| 백그라운드 동작 | 화면 꺼짐·다른 앱 사용 중에도 계속 동작, 알림 영역에 진행 상태 표시 |
| 화면 꺼짐 방지 | 운동 중에는 화면이 꺼지지 않도록 하는 옵션 |

### 이후 단계
| 단계 | 기능 |
|---|---|
| 2차 | EMOM, AMRAP, 스톱워치 모드 / 동작 이름이 들어간 루틴 (예: "버피 40초") |
| 2차 | 운동 기록 (날짜별 총 운동 시간, 완료한 루틴) |
| 3차 | iOS 출시, 홈 화면 위젯, 워치 연동 |
| 3차 | 루틴 공유, 백업/복원 |

### 범위 밖 (하지 않음)
- 운동 동작 영상·자세 가이드 콘텐츠
- 식단·체중 관리
- 소셜/커뮤니티 기능

## 6. 출시 전략

1. **Android 먼저 출시**: Google Play에 내부 테스트 → 비공개 테스트 → 프로덕션 순서로 출시
   - 신규 개인 개발자 계정은 프로덕션 출시 전에 비공개 테스트(일정 인원·기간) 요건이 있으므로 테스터 모집 일정을 미리 잡는다.
2. **iOS는 MVP 안정화 후**: Flutter라 코드는 공유하지만, 백그라운드 타이머·알림 동작은 플랫폼마다 따로 검증해야 한다.

## 7. 수익 모델: 무료 체험 + 한 번 구매 (2026-11-18 결정)

**광고는 넣지 않는다.** 무료로 일정 횟수 써보게 한 뒤, 정식 버전 구매로 유도한다.

| 항목 | 내용 |
|---|---|
| 무료 체험 | **운동 15회**까지 모든 기능 무료 (60초 이상 진행한 운동만 셈) |
| 체험 후 무료 | **프리셋 4개**(타바타, HIIT, 플랭크, 근력 세트)는 계속 무료 |
| 체험 후 잠김 | 내 루틴 만들기·수정·실행, 프리셋 복사해서 수정 |
| 결제 방식 | **한 번 구매** (Google Play 인앱 상품, 평생 사용). 구독 없음 |
| 가격 | 미정 (경쟁 앱 가격 조사 후 결정) |

- 이유: 타이머 같은 도구 앱은 구독에 대한 거부감이 크다. 체험 후에도 프리셋을 남겨서 "앱을 못 쓰게 됐다"는 불만 리뷰를 줄인다.
- 상세 규칙은 02 문서 10장, 화면은 03 문서 S6.
